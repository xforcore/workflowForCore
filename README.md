# workflowForCore

workflowForCore is Windows Workflow Foundation 3 (`System.Workflow.ComponentModel`, `System.Workflow.Runtime` and
`System.Workflow.Activities`), from Microsoft's .NET Framework 4.8 Reference Source, ported to .NET 10 so that
applications and libraries built on WF3, such as Composite C1's console, run their code-defined sequential and
state-machine workflows unchanged on Linux and Windows. The design, its scope and its phases are in
[issue #1](https://github.com/xforcore/workflowForCore/issues/1); the work lands through pull requests into `main`.
